Install ZN Karaoke Studio on iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Tap Add to Home Screen. If you see Open as Web App, turn it on, then tap Add.

Can’t find Add to Home Screen? Scroll down in the Share menu. If it still isn’t listed, tap Edit Actions and add it there.
